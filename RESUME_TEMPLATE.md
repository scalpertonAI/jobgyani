# Professional Resume Template

## Overview

The JobGyani platform generates beautifully formatted, ATS-friendly PDF resumes using a professional template design. The template automatically parses resume content and applies professional formatting.

## Template Features

### 1. **Header Section**
- **Name**: Large, bold (18pt), with underline separator
- **Contact Information**: Email, phone, LinkedIn, GitHub (9pt, gray)
- Clean, professional layout with proper spacing

### 2. **Section Headers**
- Bold, uppercase headings (12pt)
- Light gray background for visual separation
- Recognized sections:
  - Professional Summary / Summary / Profile
  - Work Experience / Professional Experience / Experience
  - Education / Academic Background
  - Skills / Technical Skills / Core Competencies
  - Certifications / Certificates
  - Projects / Key Projects
  - Achievements / Accomplishments
  - Languages
  - Volunteer Experience / Volunteer Work

### 3. **Content Formatting**

#### Job Titles / Degrees
- **Bold** formatting (11pt)
- Automatically detected for common roles (Engineer, Developer, Manager, Analyst, etc.)
- Extra spacing for visual hierarchy

#### Company Names & Dates
- *Italic* formatting (10pt)
- Gray color for subtle emphasis
- Automatic detection of date patterns

#### Bullet Points
- Professional bullet symbols (•)
- Proper indentation (7mm from left margin)
- Multi-line support with hanging indent
- Optimal line spacing (4.5mm)

#### Regular Text
- Clean, readable font (10pt Helvetica)
- Proper line spacing and word wrapping
- Consistent dark gray color

### 4. **Professional Spacing**
- 15mm margins on all sides
- Automatic page breaks with intelligent spacing
- Section separation for readability
- Consistent line heights throughout

### 5. **Page Management**
- A4 format (210mm x 297mm)
- Automatic page breaks when content overflows
- Page numbers in footer ("Page X of Y")
- Professional footer styling

## How It Works

### Content Parsing
The template intelligently parses the AI-generated resume text and identifies:

1. **Name**: First substantial line (< 50 characters)
2. **Contact Info**: Lines with @, phone patterns, LinkedIn, GitHub
3. **Section Headers**: Uppercase lines matching standard sections
4. **Job Titles**: Lines with common job title keywords
5. **Company/Dates**: Lines with year patterns (2020, 2021, etc.)
6. **Bullets**: Lines starting with •, -, *, or numbers
7. **Regular Text**: All other content

### Automatic Formatting
Based on content type, the template applies:
- Appropriate font sizes
- Bold/italic/regular styling
- Text colors (black, dark gray, light gray)
- Spacing and indentation
- Background colors for sections

## Best Practices

### For AI-Generated Resumes
The AI is instructed to generate resumes with:
- Clear section headings in uppercase
- Bullet points for achievements
- Company names with date ranges
- Standard formatting patterns

### For Manual Adjustments
If you need to modify the template:
- Section headers should be uppercase
- Use bullet points (•, -, *) for lists
- Include dates in YYYY or Mon YYYY format
- Keep job titles concise (< 80 characters)
- Use standard section names from the list above

## Technical Details

### Font Specifications
- **Name**: Helvetica Bold, 18pt
- **Section Headers**: Helvetica Bold, 12pt
- **Job Titles**: Helvetica Bold, 11pt
- **Company/Dates**: Helvetica Italic, 10pt

- **Primary Text**: RGB(20, 20, 20) - Almost black

- **Job Titles**: RGB(40, 40, 40) - Medium dark gray
- **Body Text**: RGB(50, 50, 50) - Medium gray
- **Contact/Dates**: RGB(60-80, 60-80, 60-80) - Light gray
- **Footer**: RGB(150, 150, 150) - Very light gray

- **Top/Bottom Margin**: 15mm
- **Left/Right Margin**: 15mm
- **Line Height**: 4.5-5mm (depending on content)
- **Section Spacing**: 4mm before sections
- **Bullet Indentation**: 7mm from left margin
